# Grammar points (HSK levels 1–3)

- `official.csv` — the official grammar list (语法等级大纲) of
  《国际中文教育中文水平等级标准》, levels 1–3: 48 + 81 + 81 points, transcribed by
  [HSK-official-Query-System](https://github.com/shawkynasr/HSK-official-Query-System) (MIT).
- `src/l1.yaml`, `src/l2.yaml`, `src/l3.yaml` — French title, explanation, pattern,
  examples and quiz for each official number, written for this app.
- `points.json` — built by `python scripts/build_grammar.py` (quiz options shuffled;
  the right answer is written first in the sources).
